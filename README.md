# StyleVault (คลังสไตล์)

โปรแกรม Windows ฟรี ทำงานในเครื่อง เก็บคลิปจากช่างตัดต่อเก่งๆ (TikTok / YouTube Shorts / Instagram Reels / Facebook)
ไว้ในคลัง แสดงเป็นการ์ดพร้อมยอดวิว เพื่อให้ Claude วิเคราะห์สไตล์แล้วนำไปใช้ตัดต่อด้วย Remotion

แผนทั้งหมดอยู่ใน `plans/style-library-plan.md` ของ Project "Windows Tools"

## เวอร์ชัน
| เวอร์ชัน | สิ่งที่ได้ |
|---|---|
| 0.3.1 | ปุ่ม "คัดลอกคำสั่งให้ Claude" คัดลอกคำสั่งเต็ม (มีที่อยู่คลัง) วางในแชตใหม่ก็เข้าใจ |
| 0.4.0 | แสดงการ์ดสไตล์ที่ Claude เขียน + ไทม์ไลน์คลิกได้ (จุดตัด/เสียงเอฟเฟกต์) + โปรแกรมเฝ้าโฟลเดอร์ รีเฟรชเองใน 1–2 วินาที |
| 0.4.1 | มีปุ่มลบ/ลองโหลดใหม่ที่เห็นชัด (ในหน้าคลิปและปุ่ม ⋯ บนการ์ด) · หน้าตั้งค่าเลื่อนได้ ตัวหนังสือไม่โดนตัด · โหลด Facebook ได้ดีขึ้น (ถ้าอ่านล็อกอินเบราว์เซอร์ไม่ได้จะลองโหลดแบบไม่ล็อกอินให้ก่อน, เพิ่ม Firefox) · ขึ้นรายละเอียดเมื่อโหลดไม่สำเร็จ |
| 0.5.0 | ถอดคำพูดในคลิป (ดาวน์โหลดตัวถอดครั้งเดียวในหน้าตั้งค่า) · ตั้งชื่อชนิดเสียงเอฟเฟกต์ให้เอง (วูบ ป๊อป คลิก ติ๊ง ฯลฯ) · กดแท็กเพื่อดูคลิปที่มีแท็กเดียวกัน · เทียบ 2 คลิปข้างกัน |
| 0.5.1 | วิดีโอและปุ่มเล่นอยู่กับที่ (เลื่อนเฉพาะฝั่งขวา) · ปุ่มปรับเสียง/ปิดเสียง เริ่มที่ 50% และจำค่าไว้ · ไทม์ไลน์แยกสี: ส้ม = เสียงเอฟเฟกต์, เทา = เสียงพูด/เพลง |
| 0.5.2 | ตัวถอดคำพูดรุ่นใหม่ (large-v3-turbo) แม่นภาษาไทยขึ้นมาก · คลิปเดิมถูกถอดใหม่ให้เอง · ลบรุ่นเก่าทิ้งให้อัตโนมัติ |
| 0.6.0 | เลขลำดับคลิป #1, #2… (ไม่เปลี่ยน ไม่ใช้ซ้ำ) · ค้นหาด้วย #เลข · Claude เรียกคลิปด้วยเลขได้ |
| 0.3.0 | อัปเดตในโปรแกรม: แถบ "มีเวอร์ชันใหม่ · อัปเดตเลย" (รอให้กดเอง) + ปุ่มเช็กเวอร์ชันใหม่ในตั้งค่า |
| 0.2.0 | เตรียมข้อมูลดิบให้ Claude อัตโนมัติ (จุดตัด, ภาพนิ่ง, contact sheet, เสียง, จังหวะเพลง, เสียงกระแทก) + `library-index.json` + `CLAUDE-README.md`; คลิปเก่าจาก 0.1.0 ถูกเตรียมย้อนหลังเอง |
| 0.1.0 | หน้าคลัง (การ์ดเท่ากัน), วางลิงก์โหลดคลิป + ยอดวิว, ลากไฟล์มาวาง, หน้ารายละเอียด + โน้ต, ตั้งค่าที่เก็บคลัง |

## สร้างเอง (สำหรับนักพัฒนา)
```
pip install -r requirements.txt pytest
python -m pytest tests
python run.py
```
GitHub Actions สร้าง `.exe` + ตัวติดตั้งให้เองทุกครั้งที่ push เข้า `main` (ดูหน้า Releases)
